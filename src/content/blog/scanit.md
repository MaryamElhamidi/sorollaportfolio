### ScanIt — Financial Literacy for Kids

**Web Application (React.js, Vite, Tailwind CSS)**

*   **What it does:** SkanIt is a web application that helps kids build financial literacy by learning through the world around them. Instead of teaching money as abstract numbers, SkanIt lets kids scan everyday items like toys, water bottles, or clothing and shows how each object connects to a real financial concept.
*   **Technology:** Built as a web app using React.js and Vite for the frontend, Tailwind CSS for styling, and Google Vision API for object detection. The backend leverages the Gemini API to simplify complex financial concepts for kids.
*   **Impact:** Turns everyday interactions into learning opportunities, making financial literacy approachable and grounded in real life.
